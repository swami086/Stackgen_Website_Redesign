Availability

`stackgen upload aws-iam-permissions` is **not supported**. It is not listed under `stackgen upload -h`.

Supported `stackgen upload` commands:

- [custom-modules](/docs/stackgen/cli-guide/usage/upload/custom-modules)
- [security-rules](/docs/stackgen/cli-guide/usage/upload/security-rules)

See [Resource Upload](/docs/stackgen/cli-guide/usage/upload/upload-resources).
