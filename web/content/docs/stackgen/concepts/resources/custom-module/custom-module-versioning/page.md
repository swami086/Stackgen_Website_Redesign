Versioning lets you manage changes to a **catalog** (shared) custom module. Each published version is fixed. To change the module, create a new version.

This page is for **catalog** modules only. For **appStack-owned** modules, edit and publish in place. See [Edit and Sync appStack-Owned Modules](/docs/stackgen/concepts/resources/custom-module/appstack-owned-module-updates).

**Features**

- **Version history**: Record of catalog module changes.
- **Version switching**: Pick which catalog version an appStack uses on the **Topology Canvas**.

**Example**: Updating a custom API Gateway module:

- **Version 1**: Basic routing.
- **Version 2**: Adds authentication.

Switch versions as needed for each deployment.
