## Patterns

- **Canvas node → route map (authoritative, 2026-08-20):** `/` `JLg8h` 9296 · `/product/aiden-for-infrastructure` `T4FJtW` 2685 · `/product/aiden-for-automation` `zTOam` 2478 · `/product/aiden-for-observability` `OAfMk` 1984 · `/product/aiden-for-sre` `bEaQH` 2346 · `/platform` `HL34b` 3338 · `/case-studies` `k1XEU` 1236 · `/case-studies/greythr` `gYoDZ` 1163 · `/case-studies/innovaccer` `YEXx8` 1026 · `/schedule-demo` `K6I26T` 816. The Wave 5 parity audit (`.superpowers/sdd/wave1-parity-report.md`) used a mapping **shifted by one frame**, which invalidated every product/platform finding and produced phantom defects such as "home hero missing dashboard" (canvas `XPc1X` is copy + one CTA, nothing else). Always re-derive from this table. Copy lives in `design-reference/README.md`.
- **Canvas-to-SVG transcription rules (parity pass, 2026-08-20):** (1) Canvas text nodes carry a box `width` **and** a `height` that encodes line count — a `256x40` box at 13px is two wrapped lines. SVG `<text>` never wraps, so always route body copy through `DiagramText` with that width. (2) Canvas diagram frames reserve their own heading/body band; when the React section renders a DOM `SectionHeaderSplit`, crop that band out of the `viewBox` or the page ships ~200-300px of empty SVG per section. (3) Page frames lay sections out **flush** (child heights sum exactly to the frame height), so section wrappers must not add their own vertical padding on top of the canvas band height. (4) Child text nodes often carry an unresolved `y` (a constant like `-4270`); only container frames hold the real offset — deriving a position from a text node's `y` silently yields 0 (this put the Agentic OS card CTA on top of its title).
- **Figma overflow fallback for dense diagram nodes:** when `get_design_context` returns sparse metadata for a full slide, split into smaller sublayers and combine their exact bounds/code. Task 10 `AidenOsDiagram` used `1:13676` for the header band, `1:13681` for the five-card grid, and a downloaded asset from `1:13616` for the center ring while keeping the top-level frame viewBox at `1920x1080`.
- **Monochrome brand assets are unusable on the dark ground:** Simple Icons SVGs ship with no `fill` (default black) and several customer brand SVGs are near-black (`#101010`, `#0E0D0F`, `#002041`). On `--color-bg-base` `#08090A` they load fine but are invisible. The canvas never uses brand artwork for these surfaces — both the logo strip and the integrations grid are text wordmarks at `#7E838C`. Prefer the canvas treatment over tinting third-party marks.
- **Parity diagnostic harness:** `web/e2e/diagnose.mjs` (node, needs the dev server on :3000) reports per-route page height, overlapping SVG `<text>` pairs, text overflowing its own frame, horizontal scroll, and logos sitting on a low-luminance background. Run it after any diagram or section change; the target is `overlaps 0 overflow 0`.
