StackGen allows you to launch your instances of [Aiden](https://aiden.stackgen.com/signup) on StackGen's own cloud. In this case, you don't have to worry about bringing up any infrastructure, Aiden is installed on the following pre-provisioned clusters:

- **Shared**: The most cost-effective option, where Aiden runs alongside other logically separated tenants on shared infrastructure. This model provides:
  - Lower operational costs.
  - Automatic scaling and management.
  - Full feature access with logical tenant isolation.
- **Dedicated**: A dedicated cluster option designed for organizations with specific performance, compliance, or security requirements. This model offers:
  - Dedicated infrastructure resources.
  - Enhanced performance and isolation.
  - Customizable configuration options.
  - VPC peering support for secure network connectivity.
- **Availability**: Cloud deployment is available across all regions of AWS, Azure, and GCP, allowing you to deploy Aiden close to your users and data for optimal performance and compliance.
