## ICP (Ideal Customer Profile)

### Firmographic
- **Primary:** Large enterprise / regulated (finance, healthcare, defense-adjacent) with complex multi-cloud production
- **Secondary:** Mid-market / growth tech with a forming or existing platform team
- **Must have:** Platform and/or SRE function that can champion and operate an Agentic OS
- **Deal shape:** Sales-led · platform fee + tiered usage · hybrid delivery (SaaS default; on-prem/air-gap when required)

### Buying committee
| Role | Fit |
|---|---|
| Champion | Head/Dir/VP Platform **or** SRE (by motion) |
| Decision Maker | CIO / VP Infra / VP Platform **or** CTO / VP Eng (flexible by deal) |
| Financial Buyer | Same as Decision Maker |
| User | Platform eng + SRE |
| Influencer | Staff/Principal eng + Security/Risk adjacent |

### Best-fit behaviors
- Already feeling agent/IDE-driven change pressure (or anticipating it)
- Own (or are accountable for) production change risk, SLOs, and policy
- Willing to adopt a control plane that spans domains — not another point tool
- Evaluate with diffs, policy results, incident timelines — not brochure category claims

### Anti-ICP
- IDE / autocomplete-only buyers (no production governance appetite)
- Hyperscaler-only shops unwilling to consider multi-cloud / customer-owned change workflows
- Orgs with no Platform or SRE owner (no champion)

### JTBD (hire StackGen for)
1. Scale autonomy without losing governance  
2. Heal inside SLOs  
3. Ship infra/pipeline change safely under policy  
4. Collapse silos into one Agentic OS  

### Primary value themes
- Autonomy at the pace of confidence  
- Foundations for ADF / governance for agent-driven change  
- Full loop: build → govern → observe → remediate
