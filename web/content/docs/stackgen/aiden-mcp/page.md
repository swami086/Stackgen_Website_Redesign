Aiden can be embedded directly into external tools like [Claude Desktop](https://claude.ai/download), [Cursor](https://cursor.com/), [Windsurf](https://windsurf.com/), or Other MCP clients, allowing your developers to interact with Aiden without ever leaving their preferred environments. Use Aiden's Model Context Protocol (MCP) server to get contextual information grounded on both up-to-date documentation and your organization's internal knowledge base.

**Check out [Aiden MCP Server](/docs/aiden/1.0/settings/api/aiden-mcp-server)** for step-by-step instructions to configure your MCP (Claude, Cursor, Windsurf, or other MCP Clients) and start using Aiden from your favorite IDE.
