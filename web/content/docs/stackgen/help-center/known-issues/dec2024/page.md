## Topology

### Fixed Version Comparison Does Not Show Connections as Difference

Click to view

**Summary**: While viewing version comparison for an appStack via the **Topology** tab, the application would not display resource connections as difference.

**Workaround**: This issue has been resolved.

### In-Progress Importing Topology Using `topology.json` Does Not Work for Group Resources

Click to view

**Summary**: While you can import `topology.json` file created from an appStack on StackGen, doing so does not populate the topology diagram under the **Topology** tab. You will be able to view all the modules and attributes that you configured in the source topology under the **IAC** tab.

**Workaround**: At present, there are no known workarounds.
