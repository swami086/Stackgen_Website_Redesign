Workspace Settings contains controls that apply to a specific workspace. Use this section to manage day-to-day operational behavior for the team working in that workspace.

**Available for roles:** AdminWorkspace Admin

**Scope:** Workspace

## What You Can Manage

- **Activity** Review recent workspace actions and execution history.

- **Agents and automation** Configure agent skills that shape how Aiden executes workspace tasks.

- **Knowledge and memory** Maintain workspace knowledge so responses stay accurate and context-aware.

- **Governance** Set approval controls for sensitive actions and operational workflows.

- **Platform** Manage members and integrations.
