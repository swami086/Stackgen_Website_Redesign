This guide will help you get started with enabling APIs in Aiden.

## Prerequisites

To begin using Aiden's APIs, generate an API key by visitng the [API Keys page](https://aiden.stackgen.com/signin?redirect=%2Fapi-keys) and following the on-screen instructions.

## Steps to Create a New API Key

Follow these steps to enable API's on Aiden:

1. From the StackGen home page, navigate to **Settings > API Keys > Create New API Key**.



![Create New API Key](https://docs.stackgen.com/assets/images/api-4ac3f9ac541493219c5ea7360e6a5269.png)

2. Enter a name for your API Key and click **Create**.
   - You can set an expiry date for your key.



     ![API Key Name](https://docs.stackgen.com/assets/images/api1-af1b614fdf23f49ec4fb32ef7bbd9167.png)
3. Copy the generated key for future use.



![Generated API Key](https://docs.stackgen.com/assets/images/api2-482abf74df12ca1156740a8601fbb677.png)










   - You can click the pencil icon **✎** to edit an API Key or,
   - Trash Bin **🗑️** to delete a generated key.
