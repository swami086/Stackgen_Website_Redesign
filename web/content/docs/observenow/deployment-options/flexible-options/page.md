StackGen offers multiple flexible deployment options. Customers can pick the right model that meets their requirements.

- SaaS on [SaaS: StackGen Cloud](/docs/observenow/deployment-options/saasopsversecloud)
  - Shared
  - Dedicated Cluster
  - Dedicated Cluster with VPC peering
  - Available on all regions of AWS, AZ and GCP
- Private SaaS on customer's cloud ( [Cluster Requirements](/docs/observenow/deployment-options/privatesaas/cluster-requirements))
  - StackGen's patent pending PrivateSaaS framework can remotely manage StackGen products running within the customer's cloud
  - This deployment is monitored and fully managed by the StackGen platform, just like SaaS
- Self hosted on customer's cloud
  - Option to self host the StackGen products within a customer's cloud is available. Please work with your customer success rep to get this enabled.
