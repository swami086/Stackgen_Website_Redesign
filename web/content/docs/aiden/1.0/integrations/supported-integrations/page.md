Currently, Aiden supports the following integrations. These integrations are not active by default in Aiden and you will need to enable them explicitly, ensuring that Aiden only interacts with systems you authorize. Each Integration requires a set of configuration parameters to enable the same.

Use the **cards** below to open shipped integration guides.
