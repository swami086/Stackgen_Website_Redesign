## What the storyboard is

A product launch film for the homepage. One story, not a looping product crop and not a YouTube talk.

| Act | Start | What the picture is |
|---|---|---|
| Why an operations factory | 0.00s | Isometric jigsaw. Violet Software Factory alone. Tokens stream off the right edge and a rate line climbs. Ops arrives as four drifting quarters. A person carries one token across the gap. Quarters lock. The two pieces click on the center tab and tokens flow through both. |
| Four ways to start | 28.46s | Push in on the joined ops piece. Seams draw on. Each quarter pulses once. |
| The four products | 33.71s | Same pattern four times: one quarter lights, the others go grey, a title card, then the product. DevOps is one skill fanning out, a trigger, two running tasks. Observability is an integrations grid, a dashboard assembling, a cloud boundary, a likely-cause card. |
| Unified context | 111.40s | Pull back. A plate slides under all four quarters. Connectors drop. The chip “rollback fixed checkout” travels the plate. |
| Aiden OS | 122.45s | A second plate. Pills light. One action token passes a policy gate, waits for a person to tap Approve, then writes an audit line. |
| Close | 134.32s | Full assembly holds, everything lit. Lower third and one button. |
