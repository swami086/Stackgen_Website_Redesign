The **Activity** page gives you a workspace-level timeline of recent actions so you can quickly review what changed and when.

**Available for roles:** AdminWorkspace Admin

**Scope:** Workspace

![Activity page](https://docs.stackgen.com/assets/images/activity-4e4414799b407b8239ae0079c460074e.png)

Use this page to:

- Track recent Aiden interactions and workflow events.
- Review updates across conversations and workspace operations.
- Confirm recent execution history before deeper investigation.

For [role and access details](/docs/aiden/2.0/settings/roles-and-access), follow this guide.
