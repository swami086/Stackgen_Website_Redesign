# Operational Context Graph Motion Storyboard

## Motion Thesis
The focal sequence represents a vertical "execution wave", similar to an n8n workflow run. Energy travels **DOWN** the spine of the diagram:
`prompt` → `Intent Router pulse` → `assemblies light L→R` → `sources converge on checkout-api` → `OS chips settle`.

## Frames
- **Frame A (t=0%)**: Prompt dim, connectors undrawn, assemblies idle, sources muted.
- **Frame B (t=35%)**: Prompt active, Intent Router glowing/pulsing, beam traveling down dashed connector.
- **Frame C (t=70%)**: Assemblies sequentially lit (Build→Operate→Observe→Remediate), green border alive.
- **Frame D (t=100%)**: Spider paths drawn into `checkout-api` (center bright), OS chips present.

## Code Mapping to Motion Primitives
- **Reveal**: Used for the prompt activation and OS chips settling.
- **Stagger**: Used for sequentially lighting the assemblies (Aiden for Infrastructure, Aiden for Automation, Aiden for Observability, Aiden for SRE) left to right.
- **DrawPath**: Used for drawing the spider paths from the 6 source chips converging into `checkout-api`.
- **Beam**: Used for the energy traveling down the dashed connector spine from the Intent Router pill.
