The StackGen CLI provides a powerful command-line interface to interact with StackGen, allowing you to configure, deploy, and manage your infrastructure efficiently. Whether you are working with a cloud-based service or an on-premises installation, the StackGen CLI offers a streamlined experience for infrastructure as code (IaC) generation and deployment.

## What is StackGen CLI?

StackGen CLI is a command-line tool that enables you to:

- Automate infrastructure generation and deployment.
- Sideload your custom and governance policies.
- Interact with repositories for version control and IaC retrieval.
- Configure authentication and security settings.
- Seamlessly integrate with existing workflows.

## Why Use StackGen CLI?

- Automation: Run infrastructure generation and deployments directly from the CI pipeline.
- Flexibility: Works with both StackGen cloud and on-premises installations.
- Simplicity: Provides an intuitive and easy-to-use command structure.
- Scalability: Supports both small-scale and enterprise-level infrastructure projects.
