The `stackgen resource` command is used for resource management tasks such as listing supported resource types and managing the configuration of your resources within appStacks. This command helps you work with various resource types across different cloud providers.

## Usage

```bash
stackgen resource [command]
```

## Subcommands

Here's an overview of the available subcommands:

### [type](/docs/stackgen/cli-guide/usage/manage/type)

List and filter the resource types supported by the StackGen platform. This subcommand provides detailed information about available resources, helping you identify what resource types can be used in your infrastructure. You can filter results by provider, deployment type, or search for specific resource patterns.
